# 真實歷史資料回測：S1、S2、S3（2026-11 診斷）

研究期間：2026-11-16 至 2026-11-23。只做研究，不下單、不連券商。

**這些都是代理資料的診斷結果，不是正式績效。** 價格用大台 TXFR1 連續合約代替小台各月份的真實成交，這不符合本 repo「使用真實合約價格」的規範。保證金和交易日曆也都是近似值。結論只能用來判斷「值不值得再投入」，不能當作策略的績效紀錄。

**結論：S1、S2、S3 在成本後都沒有可以交易的優勢。** 完整的跨策略統整（含賽局假設、權值股、個股期貨驗證）在 fadacai repo 的 `research/strategy_search_20261118/README.md`。

## 資料與轉換

資料放在 repo 外，路徑寫死在 runner 裡（`D:\fadacai\期貨價差\data\`），不納入版本控制。

- **價格**：TXFR1 1 分與 5 分 K，期間 2016 至 2026-09。CSV 的 `contract` 欄在換月時比實際晚切換，所以近月改由交易日曆推算。CSV 的 `trading_date` 在午夜後的列差一天。
- **現貨**：TAIEX 5 分 K。
- **法人**：FinMind 的 TX 和 MTX 三大法人未平倉部位，期間 2018-06 至 2026-11。
- **利率與股利**：央行重貼現率取自 data.gov.tw 資料集 10783。TAIEX 股利點數用報酬指數反推：`P(t-1)*TR(t)/TR(t-1) - P(t)`。
- **`build_gtts_inputs.py` 的產出**：
  - 交易日曆：以 FinMind 交易日和 MTX 最後交易日為準，沒有經過期交所核對。
  - 保證金：取名目金額的 7%，維持保證金是原始保證金的 0.767 倍，是近似值。
  - MTX 各月份 5 分 K：由期交所 30 天逐筆資料轉成，只涵蓋 2026-08-11 到 2026-11-18。

## 結果

### S3 regime breakout（`run_s3_real.py`）

- 期間是 2026-01 至 2026-09，所有 K 棒都標成合約 202612（`S3_PROXY=1`）。原因是 `breakout_features` 需要連續 20 個同月份的日盤，而連續合約一換月就會中斷。
- 結果：S3 4 筆 -5,620 元；Donchian 53 筆 -13,056；ATR 49 筆 -30,044。
- 多數進場被 `trade_risk_limit` 擋掉，因為 1 口的停損風險超過權益的 0.5%。

### S1 法人 Bayes（`run_s1_real.py`）

| 版本 | 樣本外 2023 至 2026-09 |
|---|---|
| 原版，1 天變化 | Bayes -10,826（33 筆）；logistic -9,066（11 筆）；Brier 0.254 |
| 5 天變化（`S1_HORIZON=5`） | `institutional_net` +31,940（312 筆） |
| 20 天變化（`S1_HORIZON=20`） | `institutional_net` +70,609（308 筆） |

20 天版本的穩健性檢驗（`s1_checks.ps1`）：
- **只有多單**：結果全部是多單。
- **年度淨利**：2023 年 +8,831、2024 年 -35,241、2025 年 +7,238、2026 年 +89,781（19 筆）。
- **統計檢驗**：t=0.83，置換檢驗 p=0.116，Bonferroni 修正（×3）後 0.35。用 10 天變化 p=0.51，40 天變化 p=0.087。
- **成本壓力**：手續費提高到 50 元或 100 元、滑價 2 tick 時，完全沒有下單。
- **2026-09 之後的保留期**（`S1_HOLDOUT=1`，用逐筆資料轉成的 MTX 真實月份 K 棒）：5 筆，+8,864 元。樣本太少，不能下結論。

**Bayes 模型的診斷**：
- 外資 20 天的 IC 是 0.08 到 0.12；投信和自營商接近 0，或在不同期間正負號相反。
- Platt 校準只用訓練期最後 20%（約 200 筆）。1 天版的權重是 -0.186，等於把方向翻反。
- 結論是訊號太弱、校準樣本太少，不是正則化太強，加大模型複雜度不會改善。

### S2 基差回歸（`run_s2_real.py`）

- 期間 2017-06 至 2026-09。基差 z-score 只用同一月份計算，所以每個近月分開跑一次回測，每段的權益都從頭開始。
- 基差策略：4,306 筆，毛利 +183,000，成本 782,392，淨利 -599,392。
- 只看價格的基準：淨利 -1,119,446。
- 基差有一點毛利，但成本是毛利的 4 倍多。

## 重跑

在本 repo 根目錄執行：

```
uv run --locked python research/real_data_20261118/run_s3_real.py   # 參數見檔頭
uv run --locked python research/real_data_20261118/run_s1_real.py 2026-09-04
uv run --locked python research/real_data_20261118/run_s2_real.py 2017-06-01 2026-09-04
```

- `build_gtts_inputs.py` 需要環境變數 `GTTS_REPO`，指向本 repo，用來讀 `configs/contracts.yaml`。
- `s1_checks.ps1` 也需要 `GTTS_REPO`。
- 這些 runner 只放在這個資料夾，沒有加進 `src/gtts`，也沒有加測試。
